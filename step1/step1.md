## 1. 이 Step이 필요한 이유

### 1-1. 전체 파이프라인에서의 위치

본 프로젝트는 7단계 파이프라인으로 구성된다:

```
S1 궤적 생성 → S2 표적 분류 → S3 칼만 추적 → S4 팬/틸트 PID
  → S5 리드 조준 → S6 포획 판정 → S7 몬테카를로 성공률
```

**Step 1은 이 파이프라인 전체의 입력(Input)이다.** 침입 드론이 어떤 물리적 경로를 따라 접근하는지를 먼저 정의하지 않으면 이후 분류기, 추적기, 제어기 어느 것도 테스트할 수 없다.

### 1-2. 구체적 역할

| 역할 | 설명 |
|---|---|
| Ground-truth 생성 | 이후 단계의 정답 레이블 역할 (분류기 학습/검증 기준) |
| 물리 기반 시나리오 | 현실적 속도·고도·이탈량을 갖는 침입 데이터 |
| Step 2 특징벡터 사전 확인 | 궤적 각도 α를 1 Hz 샘플로 미리 계산해 분류 가능성 검증 |
| 검증 지표 확보 | 고도유지 범위·터미널 속도·이탈량으로 물리 모델 타당성 정량 확인 |

### 1-3. 대안이 없는 이유

실제 침입 드론 비행 데이터(GPS 로그, 레이더 추적 데이터)는 보안상 공개되지 않는다. 논문에서 검증된 물리 파라미터로 시뮬레이션을 생성하는 것이 현실적으로 유일한 대안이다.

## 3. 이 논문을 응용한 이유

### 3-1. Hattenberger (2023) — 방향별 항력 분리

기존 드론 시뮬레이션 코드의 대부분은 단일 항력계수(Cd)를 사용한다:

```
F_drag = -½ρ·Cd·A·|v_rel|·v_rel    (단일 Cd, 방향 무관)
```

문제점: 쿼드로터는 **프로펠러 회전면 방향에 따라 형상 저항이 다르다.** 수직 방향은 디스크 면이 정면으로 향하기 때문에 수평보다 항력이 크다. 단일 Cd로 모델링하면 수직 감속이 과소/과대 추정된다.

Hattenberger 2023은 실험적으로 이를 분리 측정하여 Cd_h=0.47, Cd_v=0.77을 제시했다. 이 값을 적용하면 수직 기동(고도유지 복원, 회피 기동)이 물리적으로 더 정확해지고, 이후 칼만 필터의 프로세스 노이즈 Q 행렬 설계에도 영향을 준다.

**응용 이유:** SCIE 저널 실측 데이터 기반 + 무료 접근 가능 + 250mm급 쿼드로터에 직접 대응하는 파라미터

---

### 3-2. Siqueira (2018) — 멱함수 풍속 프로파일

단순 일정 풍속 모델(v_wind = const)은 고도 의존성을 무시한다. 실제 대기경계층에서는 지표 마찰로 인해 **고도가 높을수록 풍속이 빨라진다.** 순항고도 30m에서 지표(기준 10m)보다 약 15% 빠른 풍속이 적용되어야 현실적이다.

WVU/Siqueira 모델은 이 효과를 멱함수로 단순화한 표준 공학 모델이며, Hellmann 지수 α_w=0.14는 개방 지형(도심 외곽, 공항 인근)의 표준값으로 널리 인용된다.

**응용 이유:** 표준 기상 공학 모델 + 구현이 단순(단항식) + ode45 내부 반복 호출 시 연산 부담 없음 + 결정론적(재현 가능)

---

### 3-3. Springer Neural C&A (2026) — 고도유지 ±2m, 궤적 각도 α

이 논문은 드론과 새를 **궤적 특징벡터**로 구별하는 분류기를 제안한다. 핵심 관찰은 드론이 자율비행 시 고도를 ±2m 이내로 유지하는 경향이 있다는 점이다. 이를 시뮬레이션에서 재현하려면 단순 중력 보상(F_z = mg)으로는 부족하고 피드백 제어기가 필요하다.

또한 이 논문이 Step 2의 분류 특징벡터로 제안하는 **궤적 각도 α**를 Step 1에서 미리 계산해 검증함으로써, Step 2 구현 전 α 값의 분리 가능성(직선 ≈0°, 회피 최대 ~0.38°)을 확인한다.

**응용 이유:** Step 2~3과의 연속성 확보 + 고도유지 특성이 검증 지표로 직접 사용 + 2026 SCIE로 최신 기준 제시

## 4. 사용된 수식

### 4-1. 드론 3D 운동방정식 (`drone_dynamics.m`)

상태벡터: **x** = [p_x, p_y, p_z, v_x, v_y, v_z]ᵀ (위치 m, 속도 m/s)

**뉴턴 제2법칙:**
```
m · dv/dt = F_thrust + F_drag − m·g·ẑ
```

**위치 미분:**
```
dp/dt = v
```

`ode45`에 넘기는 함수 형태:
```
dxdt = [v_x; v_y; v_z; a_x; a_y; a_z]
a = (F_thrust + F_drag) / m − [0; 0; g]
```

---

### 4-2. 상대속도 분해

바람의 영향은 절대속도가 아닌 **공기에 대한 상대속도**로 계산한다:

```
v_rel = v_drone − v_wind(t, z)

v_rel_h = [v_rel_x; v_rel_y; 0]    ← 수평 성분 (3D 벡터, z=0)
v_rel_v =  v_rel_z                   ← 수직 스칼라
```

---

### 4-3. 방향별 항력 (Hattenberger 2023, Table 2)

**수평 항력:**
```
F_drag_h = −½ · ρ · Cd_h · A · |v_rel_h| · v_rel_h
```

**수직 항력:**
```
F_drag_v = −½ · ρ · Cd_v · A · |v_rel_v| · [0; 0; v_rel_v]
```

**합력:**
```
F_drag = F_drag_h + F_drag_v
```

| 기호 | 값 | 의미 |
|---|---|---|
| ρ | 1.225 kg/m³ | 해면 공기밀도 |
| Cd_h | 0.47 | 수평 항력계수 [Hattenberger 2023] |
| Cd_v | 0.77 | 수직 항력계수 [Hattenberger 2023] |
| A | 0.073 m² | 유효 전면적 (250mm 쿼드로터) |

구현 시 zero-division 방지:
```matlab
if mag_h > 1e-6:  F_drag_h = -half_rho_A * Cd_h * mag_h * v_rel_h
else:             F_drag_h = 0   % 정지 상태
```

---

### 4-4. 고도 의존 풍속 프로파일 (Siqueira 2018 / Hellmann Law)

```
v(z) = v_ref · (z / z_ref)^α_w
```

| 기호 | 값 | 의미 |
|---|---|---|
| z_ref | 10 m | 기준 고도 |
| α_w | 0.14 | Hellmann 지수 (개방 지형) |
| v_ref | 시나리오별 | 기준 고도에서의 기저 풍속 |

순항고도 30m에서의 보정 배율:
```
(30/10)^0.14 = 3^0.14 ≈ 1.162   → 지표 대비 약 16.2% 증가
```

**시나리오별 풍속 입력:**

| 시나리오 | 기저풍 (X) | 돌풍 성분 | 측풍 (Y) |
|---|---|---|---|
| calm | 0 m/s | — | — |
| light | 5 + 0.5·sin(0.5t) m/s | 0.5 m/s 사인파 | — |
| strong | 15 + 2·sin(0.3t) m/s | 2 m/s 사인파 | 2·cos(0.2t) m/s |

고도 보정은 수평 성분(X, Y)에만 적용. 수직 성분은 0 (수직 돌풍 미모델링, Step 3에서 노이즈로 처리).

---

### 4-5. 고도유지 PD 제어기 (`guidance_law.m`, Springer 2026)

```
e_z = z_target − z_pos               ← 고도 오차
F_z = m · (g + Kp_z · e_z − Kd_z · ż)
```

| 기호 | 값 | 의미 |
|---|---|---|
| z_target | 30 m | 순항 목표고도 |
| Kp_z | 20 N/m | 비례 게인 |
| Kd_z | 8 N·s/m | 미분 게인 |

**감쇠 설계:**
- 고유주파수: ω_n = √(Kp_z/m) = √(20/1.35) ≈ 3.85 rad/s
- 감쇠비: ζ = Kd_z / (2·m·ω_n) = 8 / (2·1.35·3.85) ≈ 0.77 (준임계 감쇠)

Kp=20, Kd=8은 응답이 빠르면서 과도 진동을 억제하는 준임계 감쇠 조건으로 선정.

---

### 4-6. 수평 접근 추력 (`guidance_law.m`)

```
h_dir = [1; 0; 0]  (단위벡터, X 방향 접근)
F_approach = T_approach · h_dir    (T = 13 N)
```

---

### 4-7. 회피 기동 추력 (evasive 모드)

**수평 측방향 회피:**
```
lat = [−h_dir_y; h_dir_x; 0]      ← 접근 방향에 수직인 수평벡터
a_lat = A_evade · sin(2π · f_evade · t)
F_lat = m · a_lat · lat
```

**수직 방향 회피 (위상 오프셋 적용):**
```
a_vert = A_evade_z · sin(2π · f_evade · 1.5t + π/4)
F_vert = [0; 0; m · a_vert]
```

**총 추력 (evasive):**
```
F_thrust = F_approach + F_alt + F_lat + F_vert
```

| 기호 | 값 | 의미 |
|---|---|---|
| A_evade | 3.0 m/s² | 수평 회피 가속 진폭 |
| A_evade_z | 1.5 m/s² | 수직 회피 가속 진폭 |
| f_evade | 0.3 Hz | 회피 주파수 |

수평과 수직에 서로 다른 주파수 비율(×1.5)과 위상 오프셋(π/4)을 적용해 궤적을 불규칙하게 만든다.

---

### 4-8. 궤적 각도 α (Step 2 분류 특징벡터, Springer 2026)

1 Hz 고정 샘플링에서 연속 속도벡터 사이의 각도:

```
α_i = arccos( v_i · v_{i+1} / (|v_i| · |v_{i+1}|) )   [degrees]
```

구현 시 수치 클리핑:
```matlab
acosd( max(-1, min(1, dot(v_i, v_{i+1}) / (norm(v_i)*norm(v_{i+1}) + 1e-9) )) )
```

**1 Hz 고정 샘플링을 사용하는 이유:**
ode45는 가변 스텝 적분기로, 내부적으로 연속된 두 점 사이의 Δt가 매우 작을 수 있다. 이 경우 이웃 벡터 방향 차이도 극소화되어 α ≈ 0이 되는 수치적 부작용이 생긴다. `interp1`로 1초 간격 샘플을 추출해서 해결한다.

---

### 4-9. 풍력 이탈량 (편차 계산)

ode45는 시나리오마다 다른 시각에서 상태를 출력하므로 직접 인덱스 비교 불가. `interp1`로 공통 시간축 보간 후 거리 계산:

```
t_common = linspace(0, min(T_s1, T_s2), 500)
x1_i = interp1(t1, x1_pos, t_common)   ← S1 위치 보간
x2_i = interp1(t2, x2_pos, t_common)   ← S2 위치 보간
deviation(t) = ||x2_i(t) − x1_i(t)||_2
```

이전 구현 버그: 인덱스 직접 비교(`x2(1:n,:) - x1(1:n,:)`) → ode45의 비균일 시간축으로 다른 시각의 위치를 빼는 문제 발생. **2026-09-24 interp1 보간으로 수정.**

## 7. 논문 응용의 장점 및 단점

### 7-1. Hattenberger 2023 항력 모델

**장점**

| 장점 | 설명 |

| 물리적 정확도 | Cd_h≠Cd_v로 수직 감속 특성 분리 재현 → 고도유지 실패 조건 포착 가능 |
| 검증된 수치 | 실험 측정값 기반 → Step 3 EKF의 Q 행렬 대각 원소 비율 설계에 근거 제공 |
| 쿼드로터 특화 | 250mm급 상업용 드론에 직접 대응 |
| 코드 단순성 | 항력을 수평/수직 두 벡터로 분해하면 코드 구조가 명료함 |

**단점**

| 단점 | 설명 |
|---|---|
| 고정 자세 가정 | 쿼드로터가 수평 이동 중 기울어질 때(roll/pitch) 실효 전면적 A 변화 미반영 |
| 단일 기종 | 다른 기종(fixed-wing, tilt-rotor)의 Cd는 완전히 다름 |
| 난류 미포함 | 항력은 평균 풍속 기반; 순간 난류 변동이 A 값에 미치는 영향 무시 |
| AoA 의존성 | 받음각(Angle of Attack)에 따라 Cd가 변하지만 여기서는 상수 처리 |

### 7-3. Springer 2026 PD 고도유지

**장점**

|---|---|

|---|---|

| 스텝 외란 미대응 | 갑작스러운 돌풍(스텝 입력) 시 과도 응답에서 ±2m를 일시적으로 초과할 수 있음 |
| 단일 순항고도 | 실제 침투 드론은 지형 추적(TF/TA)으로 고도를 가변시킬 수 있음 |
