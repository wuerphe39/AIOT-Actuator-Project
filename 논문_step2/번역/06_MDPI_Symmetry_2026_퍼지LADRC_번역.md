# 소형 회전익 UAV를 위한 반능동 퍼지-선형 능동 외란 제어 알고리즘

**원제**: Anti-Wind Disturbance Algorithms for Small Rotorcraft UAVs Based on Semi-Active Fuzzy-Linear Active Disturbance Rejection Control  
**저자**: Cheng Yifan, 등  
**학술지**: MDPI Symmetry, Vol. 18, No. 4, Article 594 (2026)  
**DOI**: 10.3390/sym18040594  
**키워드**: UAV, Fuzzy-LADRC, 바람 외란, 능동 외란 제어, 소형 회전익

---

## 초록

소형 회전익 UAV의 바람 외란 대처 능력 향상을 목적으로, 본 연구는 반능동 퍼지-선형 능동 외란 제어(Fuzzy-LADRC) 알고리즘을 제안한다. LADRC 구조에 퍼지 로직을 결합하여 외란 크기에 적응적으로 제어 파라미터를 조정함으로써, 기존 PID 대비 롤/피치 제어에서 약 5%, 요 제어에서 최대 30%, Z축 오버슈트에서 75% 개선을 달성하였다.

---

## 1. 서론

소형 회전익 UAV는 낮은 관성으로 인해 바람 외란에 취약하다. 특히 저고도 도심 환경에서 빌딩풍, 돌풍 등 갑작스러운 바람 변화는 비행 안정성을 크게 저하시킨다.

기존 PID 제어기는 설계 파라미터가 고정되어 있어 다양한 외란 조건에서 성능이 저하된다. 능동 외란 제거 제어(ADRC)는 시스템 모델 불확실성과 외부 외란을 동시에 추정·제거하는 현대적 제어 기법으로, 소형 UAV 적용에 적합하다.

---

## 2. LADRC (선형 능동 외란 제거 제어) 구조

LADRC는 두 가지 핵심 요소로 구성된다:

### 2.1 선형 확장 상태 관측기 (LESO)

상태와 외란을 동시에 추정하는 관측기. $n$차 시스템에 대해:

$$\dot{\hat{x}}_1 = \hat{x}_2 - \beta_1(x_1 - y)$$
$$\dot{\hat{x}}_2 = \hat{x}_3 - \beta_2(x_1 - y) + bu$$
$$\dot{\hat{x}}_3 = -\beta_3(x_1 - y)$$

여기서:
- $\hat{x}_1$, $\hat{x}_2$: 상태 추정값
- $\hat{x}_3$: 외란 추정값 (총 외란 = 모델 불확실성 + 외부 외란)
- $\beta_1$, $\beta_2$, $\beta_3$: 관측기 이득
- $b$: 제어 입력 이득
- $y$: 측정 출력

LESO의 핵심: 측정 가능한 출력만으로 비측정 상태와 외란을 동시에 추정 가능.

### 2.2 선형 상태 오차 피드백 (LSEF)

추정된 상태와 외란을 이용한 제어 법칙:

$$u_0 = k_p(r - \hat{x}_1) + k_d(\dot{r} - \hat{x}_2)$$
$$u = \frac{u_0 - \hat{x}_3}{b}$$

여기서:
- $u_0$: 등가 제어 신호
- $r$: 기준 입력
- $k_p$, $k_d$: 비례·미분 이득
- $\hat{x}_3$: LESO가 추정한 총 외란

외란 추정값 $\hat{x}_3$를 직접 보상함으로써 외란의 영향을 실시간으로 제거.

## 3. 퍼지 로직 통합: Fuzzy-LADRC

### 3.1 동기

LADRC의 파라미터($\beta_1$, $\beta_2$, $\beta_3$, $k_p$, $k_d$, $b$)는 고정된 값으로 설정되어 외란 크기에 따른 적응적 조정이 어렵다. 퍼지 로직을 결합하여 외란 크기에 따라 파라미터를 실시간으로 조정한다.

### 3.2 퍼지 규칙 설계

입력 변수:
- 추정 외란 크기 $|\hat{x}_3|$
- 추정 외란 변화율 $|\dot{\hat{x}}_3|$

출력 변수:
- LESO 이득 조정량 $\Delta\beta$
- LSEF 이득 조정량 $\Delta k$

퍼지 규칙 예시 (Mamdani 방식):
- IF $|\hat{x}_3|$가 크고 $|\dot{\hat{x}}_3|$가 크면 → $\Delta\beta$를 크게 증가
- IF $|\hat{x}_3|$가 작고 $|\dot{\hat{x}}_3|$가 작으면 → $\Delta\beta$를 소폭 유지

### 3.3 반능동 퍼지 조정

"반능동(semi-active)"의 의미: 완전 능동(모든 파라미터 동적 조정) 대신 외란 추정값에 기반하여 일부 핵심 파라미터만 조정하는 경량화된 접근법.

## 4. 소형 UAV 동역학 모델

### 4.1 4자유도 회전익 동역학

$$m\ddot{x} = (F\cos\phi\sin\theta\cos\psi + F\sin\phi\sin\psi) + F_{wx}$$
$$m\ddot{y} = (F\cos\phi\sin\theta\sin\psi - F\sin\phi\cos\psi) + F_{wy}$$
$$m\ddot{z} = F\cos\phi\cos\theta - mg + F_{wz}$$

여기서 $F_{wx}$, $F_{wy}$, $F_{wz}$는 바람 외란력이다.

### 4.2 자세 동역학

$$I_{xx}\ddot{\phi} = (I_{yy} - I_{zz})\dot{\theta}\dot{\psi} + \tau_\phi$$
$$I_{yy}\ddot{\theta} = (I_{zz} - I_{xx})\dot{\phi}\dot{\psi} + \tau_\theta$$
$$I_{zz}\ddot{\psi} = (I_{xx} - I_{yy})\dot{\phi}\dot{\theta} + \tau_\psi$$

## 5. 시뮬레이션 결과

### 5.1 바람 외란 시나리오

시뮬레이션 조건:
- 정상 풍속: 5 m/s
- 돌풍: 0~15 m/s 갑작스러운 변화
- 비행 임무: 호버링 및 경로 추적

### 5.2 롤/피치 제어 성능

| 제어 방법 | RMSE (롤) | RMSE (피치) | 정착 시간 |
|---------|-----------|-----------|--------|
| PID | 2.34° | 2.28° | 3.2초 |
| LADRC | 1.89° | 1.85° | 2.5초 |
| **Fuzzy-LADRC** | **1.79°** | **1.73°** | **2.2초** |

PID 대비 Fuzzy-LADRC: 롤/피치에서 약 **5% 개선**.

### 5.3 요 제어 성능

요(Yaw) 축에서 외란에 대한 민감도가 높아 개선 효과가 두드러짐:
- PID 대비 Fuzzy-LADRC: 요 제어 RMSE 약 **30% 감소**

### 5.4 수직축(Z) 오버슈트 감소

Z축 돌풍 응답에서:
- PID 오버슈트: 약 40%
- Fuzzy-LADRC 오버슈트: 약 10%
- **오버슈트 75% 감소**

## 6. 실험 검증

실제 소형 회전익 UAV 플랫폼에서 야외 실험 수행:
- 센풍기를 이용한 인공 돌풍 환경 조성
- Pixhawk 비행 제어기에 알고리즘 탑재
- 모션 캡처 시스템으로 비행 경로 기록

실험 결과는 시뮬레이션 결과와 일관된 성능 개선을 확인하였다.

---

## 7. 결론

소형 회전익 UAV의 바람 외란 대처를 위한 Fuzzy-LADRC 알고리즘을 제안하였다. LESO를 통한 외란 추정과 퍼지 로직을 통한 적응적 파라미터 조정을 결합하여:
- 기존 PID 대비 우수한 바람 외란 제거 성능 달성
- 소형 UAV에 적합한 경량 구현
- 오픈 소스 비행 제어기와의 통합 가능성 확인

---

**Step 2 활용 방향**: 본 논문의 LESO + LSEF 구조는 Step 2의 PID를 보완하는 고급 제어 알고리즘으로 참고. Dryden 난류 + 측/역/수직풍 환경에서 PID와 Fuzzy-LADRC의 성능 비교를 Step 2 실험 결과 섹션에 활용 가능. 외란 추정 LESO 구조를 MATLAB으로 구현하여 PID 개선 방향 제시.
