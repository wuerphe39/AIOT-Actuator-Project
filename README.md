# 도로-교각 통합 능동 진동 제어 연구
**IoT 액추에이터 팀프로젝트** · 2026년 2학기

---

## 프로젝트 개요

고속도로 교량에 IoT 센서·액추에이터 기반 **능동 진동 제어(Active Vibration Control)** 시스템을 적용하여, 차량 통행 진동과 바람·지진에 의한 흔들림을 실시간으로 상쇄하는 연구.

| 항목 | 내용 |
|:---|:---|
| 기간 | 12주 (2026.09 ~ 2026.12) |
| 팀 구성 | 4인 |
| 시뮬레이션 도구 | MATLAB/Simulink |
| 실물 하드웨어 | 아두이노 + MPU6050 + 솔레노이드/보이스코일 액추에이터 |

### 연구 구조

```
1단계 (핵심): 도로 상판 하부 매립형 AVC
  → 차량 통행 진동을 실시간 감지, 반대 위상으로 상쇄 (노이즈캔슬링 원리)

2단계 (확장): 교각 상단 능동질량감쇠기(AMD)
  → 바람·지진에 의한 수평 흔들림을 무게추 능동 구동으로 감쇠
```
