## 1. 이 Step이 필요한 이유

### 1-1. 전체 파이프라인에서의 위치

```
S1 궤적 생성 → [S2 표적 분류] → S3 칼만 추적 → S4 팬/틸트 PID
  → S5 리드 조준 → S6 포획 판정 → S7 몬테카를로 성공률
```

Step 2는 **Step 1의 드론 궤적과 새로 생성한 새 궤적을 구분하는 분류기**를 구현한다. Step 3(칼만 추적)은 표적이 드론임이 확인된 경우에만 동작시킬 수 있기 때문에, 분류기는 포획 시스템의 **1차 필터** 역할을 한다.

### 1-2. 구체적 역할

| 역할 | 설명 |
|---|---|
| 오탐(False Positive) 방지 | 새를 드론으로 잘못 분류 → 불필요한 포획 시도 차단 |
| 미탐(False Negative) 방지 | 드론을 새로 잘못 분류 → 침입 드론 놓침 방지 |
| 특징벡터 생성 기준 확립 | Step 1의 α 외에 추가 특징을 정의·검증 |
| 풍난류 조건 확장 | Dryden 모델로 현실적 노이즈를 추가해 분류기 강인성 확보 |

### 1-3. 새 궤적이 필요한 이유

실제 새 비행 데이터(GPS 로그)는 공개 데이터셋이 없거나 레이블 품질이 낮다. 논문에서 보고된 새의 운동 특성(날갯짓 주기, 고도 변동 범위, 불규칙 궤적)을 기반으로 **합성 새 궤적을 생성**하는 것이 현실적으로 유일한 대안이다. 논문에 따르면 새는 고도 변화가 크고(± 5~10 m 수준), 속도 표준편차가 크며, 궤적 각도 α가 드론보다 현저히 크다.

## 3. 이 논문을 응용한 이유

### 3-1. Liu 2021 (IEEE Access) — 랜덤 포레스트 분류기

가장 직접적으로 연관된 선행 연구다. 레이더 추적 데이터를 사용하므로 본 프로젝트의 시뮬레이션 데이터와 구조가 동일하다(시계열 위치·속도 → 특징 추출 → 분류). 랜덤 포레스트를 선택한 이유:

- 특징 중요도(feature importance) 자동 출력 → 어떤 특징이 분류에 기여하는지 분석 가능
- 소규모 데이터셋(시뮬레이션 수백~수천 궤적)에서 과적합에 강함
- 결과 해석 용이 → 발표 시 특징 기여도 시각화 가능

**응용 이유:** SCIE 실험 근거 + 동일 문제 구조 + 해석 가능한 모델

---

### 3-2. Dryden 모델 (NASA NTRS 2019 + IOP 2018)

Step 1의 풍속 모델(Hellmann 멱함수)은 **평균 풍속**만 모델링하고 순간 난류는 무시한다. 실제 환경에서 드론과 새 모두 같은 난류에 노출되므로, 분류기는 난류 조건에서도 동작해야 한다.

Dryden 모델은 다음 이유로 선택:
- MIL-F-8785C 군사 비행 규격의 공식 표준 → 인용 근거 명확
- MATLAB Simulink에 기본 블록으로 구현됨 → 구현 검증 용이
- 연속 PSD 기반 → ode45와 호환되는 결정론적 구현 가능 (시드 고정 시 재현 가능)
- NASA NTRS 보고서로 수식·파라미터 무료 확인 가능

**응용 이유:** 표준 모델 + MIL-SPEC 근거 + 재현성 보장 + 무료 접근 가능

---

### 3-3. MDPI Symmetry 2024 — PD → PID 고도 제어 변경

Step 1의 PD 제어기는 **정상 상태 편차(steady-state error)** 가 발생한다. 지속적 바람 외란(정풍 5 m/s, 15 m/s)이 있을 때 PD만으로는 목표 고도로 완전히 수렴하지 못하고 미세한 편차가 남는다. 분류기의 고도 특징(std(z), 고도 편차)이 제어기 성능에 오염되지 않으려면 PID가 필요하다.

MDPI Symmetry 2024 논문은 소형 로터크래프트 UAV를 대상으로 PD / PID / SMC를 비교하여 정상 바람 외란 조건에서 PID가 PD 대비 정상 상태 고도 오차를 현저히 감소시킴을 보인다.

**응용 이유:** 소형 UAV 직접 대응 + 비교 실험 근거 + SCIE 오픈 액세스

## 4. 사용된 수식

### 4-1. Dryden 대기 난류 모델

Dryden 모델은 대기 난류를 **성형 필터(shaping filter)** 로 표현한다. 백색 잡음 w(t)를 필터에 통과시켜 실제 난류 스펙트럼을 가진 속도 섭동을 생성한다.

**종방향 (u) 난류 전달함수:**
```
H_u(s) = σ_u · sqrt(2L_u / (π·V)) · (1 / (1 + (L_u/V)·s))
```

**횡방향 (v, w) 난류 전달함수:**
```
H_v(s) = σ_v · sqrt(L_v / (π·V)) · (1 + sqrt(3)·(L_v/V)·s) / (1 + (L_v/V)·s)²
```

| 기호 | 의미 | 저고도(< 300m) 값 |
|---|---|---|
| σ_u, σ_v, σ_w | 난류 세기 (m/s) | 경풍: 1.06, 강풍: 2.12 |
| L_u, L_v, L_w | 난류 스케일 길이 (m) | 고도 z와 연동 (MIL-F-8785C) |
| V | 드론 대기속도 (m/s) | 시뮬레이션 순간 속도 |

**이산 근사 (Δt 스텝, MATLAB 구현):**
```
난류 속도 = 이전값 × exp(-V·Δt/L) + σ·sqrt(1 - exp(-2V·Δt/L)) × randn()
```

→ Step 1의 결정론적 돌풍(사인파)에 이 확률적 성분을 **가산**하여 적용.

---

### 4-2. PID 고도 유지 제어기 (Step 1 PD 확장)

```
e_z(t) = z_target − z(t)           ← 고도 오차

F_z = m · (g + Kp_z·e_z + Ki_z·∫e_z dt − Kd_z·ż)
```

**적분항 Anti-Windup 처리:**
```
만약 |∫e_z| > I_max 이면  ∫e_z := sign(∫e_z) · I_max
```

| 기호 | 값 | 단위 | 의미 |
|---|---|---|---|
| Kp_z | 20 | 1/s² | Step 1과 동일 |
| Ki_z | 2 | 1/s³ | 정상상태 편차 제거 (신규 추가) |
| Kd_z | 8 | 1/s | Step 1과 동일 |
| I_max | 5 | m·s | 적분 포화 방지 상한 |

**특성방정식 (m 약분 후):**
```
s³ + Kd_z·s² + Kp_z·s + Ki_z = 0
즉,  s³ + 8s² + 20s + 2 = 0
```
세 근 모두 좌반평면에 위치 → 안정성 보장 (Routh-Hurwitz 확인).

---

### 4-3. 가속도 특징 추출

ode45 출력에서 속도 시계열을 1 Hz 샘플로 보간한 후 수치 미분:

```
a_i = (v_{i+1} − v_{i-1}) / (2·Δt)      ← 중심차분 (i = 2, ..., N-1)
```

특징으로 사용하는 값:
```
acc_mean = mean(|a_i|)       ← 평균 가속도 크기 (m/s²)
acc_std  = std(|a_i|)        ← 가속도 크기 표준편차
```

드론: 추력 제어 → 가속도 작고 안정적.
새: 날갯짓 → 가속도 크고 변동 심함.

---

### 4-4. 궤적 곡률 κ

3D 곡률은 속도벡터와 가속도벡터의 외적으로 계산:

```
κ_i = |v_i × a_i| / |v_i|³
```

1 Hz 보간 샘플에서:
```
v_i = x_s(i, 4:6)                    ← 속도벡터
a_i = (v_{i+1} − v_{i-1}) / (2·Δt) ← 중심차분 가속도

κ_i = norm(cross(v_i, a_i)) / (norm(v_i)^3 + ε)
```

특징:
```
curv_mean = mean(κ_i)     ← 평균 곡률 (1/m)
curv_max  = max(κ_i)      ← 최대 곡률
```

직선 비행: κ ≈ 0.
회피 기동 / 새 날갯짓: κ >> 0.

---

### 4-5. 호버링 감지

```
speed_i = |v_i|          ← 전속도 크기 (m/s)

hover_i = 1  if speed_i < v_hover_thresh  AND  |vz_i| < vz_thresh
        = 0  otherwise

hover_ratio = sum(hover_i) / N    ← 전체 샘플 중 호버링 비율
```

| 임계값 | 값 | 근거 |
|---|---|---|
| v_hover_thresh | 1.0 m/s | 드론 정지 비행 인정 범위 |
| vz_thresh | 0.3 m/s | 수직 진동 허용 범위 |

새는 이 조건을 만족하는 시간이 사실상 0 → hover_ratio ≈ 0 항상.
드론은 목표 도달 전 속도 감소 구간에서 hover_ratio > 0 가능.

---

### 4-6. 통계적 특징 (고도·속도·수직속도)

```
z_std     = std(z(t))           ← 고도 표준편차 (m)
spd_mean  = mean(|v_h(t)|)      ← 수평 속도 평균 (m/s)  v_h = [vx; vy]
spd_std   = std(|v_h(t)|)       ← 수평 속도 표준편차
vz_mean   = mean(|vz(t)|)       ← 수직속도 절댓값 평균 (m/s)
vz_std    = std(vz(t))          ← 수직속도 표준편차
```

**드론 vs 새 예상 분리:**

| 특징 | 드론 (예상) | 새 (예상) |
|---|---|---|
| z_std | < 1 m | > 3 m |
| spd_std | < 2 m/s | > 4 m/s |
| vz_mean | < 0.5 m/s | > 1.5 m/s |
| acc_std | < 1 m/s² | > 3 m/s² |
| curv_mean | < 0.01 1/m | > 0.05 1/m |
| hover_ratio | 0~0.1 | ≈ 0 |
| α_mean | < 1° | > 3° |

### 4-8. 분류기 입출력

**입력:** f (N개 샘플, N×7 행렬)
**출력:** y ∈ {0: 새, 1: 드론}

**로지스틱 회귀:**
```
P(y=1|f) = 1 / (1 + exp(−(w·f + b)))
```

**SVM (RBF 커널):**
```
K(f_i, f_j) = exp(−γ · |f_i − f_j|²)
결정 경계: sign(Σ α_i·y_i·K(f_i, f) + b)
```

**랜덤 포레스트:**
```
y_hat = majority_vote( T_1(f), T_2(f), ..., T_n(f) )    n = 100 트리
```

**평가 지표:**
```
Precision = TP / (TP + FP)
Recall    = TP / (TP + FN)
F1        = 2 · Precision · Recall / (Precision + Recall)
```

새를 드론으로 잘못 분류(FP)가 드론을 새로 잘못 분류(FN)보다 치명적이므로
→ **Recall(재현율) 최대화**를 1차 목표로 설정.

---

### 4-9. 새 궤적 합성 모델

새의 날갯짓을 모방한 수직 진동 + 불규칙 수평 경로:

```
z_bird(t) = z_base + A_flap · sin(2π · f_flap · t) + σ_z · randn()

v_h_bird(t) = v_base + A_gust · sin(2π · f_turn · t + φ_rand) + σ_v · randn()
```

| 파라미터 | 값 | 근거 |
|---|---|---|
| A_flap | 3~8 m | 날갯짓 고도 진폭 (Liu 2021, Springer 2026) |
| f_flap | 0.5~2 Hz | 새 날갯짓 주파수 |
| σ_z | 1~2 m | 고도 랜덤 노이즈 |
| A_gust | 2~5 m/s | 수평 속도 진폭 변화 |
| f_turn | 0.1~0.3 Hz | 방향 전환 주파수 |
| σ_v | 0.5~1.5 m/s | 속도 랜덤 노이즈 |
